## 변경 규칙

1. 변경 전후의 상태와 내용을 기록한다.
2. 사용자 발언이나 승인 날짜를 근거로 남긴다. 구현했다는 사실만으로 확정으로 승격하지 않는다.
3. 충돌하면 최신의 명시적인 사용자 결정을 우선하되 옛 기록은 폐기 사유와 함께 보존한다.
4. 수치 변경은 관련 미니게임과 평가 문서를 함께 수정한다.

## 변경 이력

- 2026-10-17: 사용자 지시로 개발 엔진을 Unity로 확정(D013). Visual Studio를 코드 편집 도구로 사용할 예정이며 Unity 게임 로직은 C#으로 작성한다. 설치된 6000.2.12f1로 `Blacksmith/`에 기본 프로젝트를 생성한다. 버전의 장기 고정, 플랫폼·입력·렌더링 방식은 미정이다. D012의 엔진 항목만 이 결정으로 대체하며 나머지 미정은 유지한다.

- 2026-10-17: 확인 가능한 5개 턴을 근거로 v0.1 작성. 과거 전체 대화 미확보 사실 명시. 제안은 미승인 상태.
