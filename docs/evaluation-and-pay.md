# 공정 평가·급여·누적 기록

## 확정 규칙

근거: S03, D006~D008.

- 참여한 공정의 건수로 급여를 계산한다.
- 작업자가 맡은 공정의 품질만 평가한다.
- 평가에 따라 급여에 약간의 차이를 둔다.
- 수습 기간의 누적 평가가 정식 입단에 영향을 준다.
- 이 시점에 완성 장비의 종합 품질을 평가하지 않는다.

## 제안: 평가 모델

각 작업은 공정별 지표를 0~100으로 정규화해 품질 점수 `q`를 만든다. 서로 다른 공정의 원시 지표는 그대로 합산하지 않는다. 지표와 가중치는 공정별 문서에서 정하며 모두 미확정이다.

입력 재료가 나쁜 경우, 전달받은 결함을 플레이어 실수로 점수에 재반영하지 않는 기준을 제안한다. 입력 대비 목표 또는 공정별 관측값을 사용한다. 재료 상태가 다음 공정에 영향을 주는 것과 평가 책임은 분리한다.

## 제안: 급여 예시

예시식: `지급액 = 반올림(공정 기본급 × (0.95 + 0.10 × q / 100))`.

기본급을 임시로 100이라 두면 q=0은 95, q=50은 100, q=100은 105다. **숫자 100과 ±5%는 설명용 제안이며 확정 경제 수치가 아니다.** 공정별 기본급을 같게 둘지도 미정이다.

여러 건의 급여는 각 작업 지급액을 합산한다. 품질 점수에 작업 건수를 다시 곱해 중복 보상하지 않는다. 중단·무효 작업의 인정 여부는 미정이므로 정식 규칙 확정 전에는 별도 상태로 기록한다.

## 제안: 누적 기록

작업별 공정, 품질, 주요 지표, 지급액, 완료 시각과 정산 여부를 저장한다. 기록부는 공정별 완료 수·평균·최근 결과를 표시한다. 입단용 집계는 단순 평균, 공정별 최소 숙련, 최근 개선 정도 중 선택이 필요하다. 한 공정만 반복해서 다른 공정을 대체할 수 있는지도 미정이다.

## 수용 기준 제안

- 같은 결과를 두 번 열거나 저장 후 재로드해도 한 번만 지급된다.
- 참여하지 않은 공정 결과를 바꿔도 내 공정 평가·급여는 변하지 않는다.
- 두 완료 작업은 두 건으로 집계되며, 미완료 작업은 임의로 완료 처리되지 않는다.
- 결과 화면에 완제품 종합 등급을 노출하지 않는다.
- 반올림과 기록 재계산 결과가 일치한다.

## 미정

실패작·재작업·중단 급여, 점수 공개 수준, 등급명, 입단 문턱, 평가 기간, 기본급, 차등 폭, 화폐 사용처.
