# 조립 미니게임

## 확정

단조보다 비중이 낮고 주조처럼 단순화한다(S02). 평가·급여는 참여한 조립 공정에 대해서만 부여한다(S03).

## 제안: 목표와 조작

지정된 부품을 안내된 결합 위치에 배치하고 완료한다. 부품을 복잡하게 자유 회전시키는 방식 대신 위치 선택 또는 간단한 정렬 입력을 첫 후보로 둔다. 부품 개수는 적게 시작하되 실제 수는 미정이다.

## 제안: 상태·평가

입력은 작업물과 부품 목록, 출력은 결합 상태와 조립 평가다. 필수 결합점별 배치 여부와 정렬 오차를 저장한다. 평가 후보는 누락 여부와 정렬 적합성이다. 단조에서 생긴 형상 결함은 조립 평가의 직접 감점으로 재사용하지 않는다.

## 제안: 피드백·검증

현재 선택 부품과 다음 결합점을 명확히 보여준다. 누락이 있으면 어느 결합점인지 알려준다. 동일 부품의 중복 장착과 중복 완료를 막는다. 올바른 배치를 했는데 숨은 타이밍 때문에 실패하지 않도록 한다. 작업 복잡도는 단조보다 낮아야 한다.

## 미정

부품 종류·수, 정렬 입력, 자동 결합, 접착·리벳 등 세부 방식, 오조립 회복, 실패 기준, 점수 공식, 장비별 변화.
