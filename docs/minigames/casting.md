# 주조 미니게임

## 확정

사용자는 조립·연마를 ‘주조처럼 단순화’한다고 설명했다(S02). 따라서 주조는 단순화 방향의 기준이다. 구체적인 주조 조작이나 점수 공식은 확인되지 않았다.

## 제안: 목표와 조작

작업에 지정된 주형에 용융 재료를 주입한다. 복잡한 유체 조작 대신 단일 입력으로 주입을 진행하고 목표 충전 구간에서 멈추는 방식을 첫 후보로 둔다. 주형 선택을 정답 맞히기 문제로 추가할지는 미정이다.

## 제안: 상태와 평가

입력은 주형 식별자와 용융 재료 상태, 출력은 주조 결과와 후속 공정용 소재다. 충전 진행량과 완료 상태를 관리한다. 목표 충전량 오차를 평가 후보로 두되 앞선 용해의 결함을 플레이어 주조 실수로 중복 감점하지 않는다.

## 제안: 피드백과 검증

목표·현재 충전량을 텍스트와 표시 막대로 함께 보여준다. 조기 중단·과충전·완료를 구분하고 완료 후 추가 입력을 막는다. 반복 수행해도 짧고 이해하기 쉬운지, 단조보다 조작 부담이 낮은지를 플레이 테스트한다. 구체 소요 시간은 미정이다.

## 미정

주형 종류, 주입 속도 조절, 냉각, 기포·수축 표현, 실패·재작업, 소재 형상 생성법, 수치·등급, 해금 순서.
