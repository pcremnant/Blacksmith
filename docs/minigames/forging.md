# 단조 미니게임

## 확정

조립·연마보다 중요한 공정이다(S02). 형태는 내부적으로 3D 데이터로 관리하며 단순화한 화면 표현은 차후 고민한다(S01). 이전 단조 논의의 상세 내용은 조회되지 않아 타격 방식과 변형 규칙은 확정할 수 없다.

## 제안: 목표와 조작

소재의 형태를 목표 형태에 가깝게 만든다. 작업 위치·도구 방향을 지정하고 타격을 입력하는 것을 조작 후보로 둔다. 타격 강도를 고정할지 조절할지, 소재 회전을 직접 할지는 미정이다. 첫 시제품은 위치와 단일 타격만 검증한다.

## 제안: 내부 데이터와 표시

작업물은 3D 형상을 가지며 목표 형상과 별도로 저장한다. 화면은 선택된 면, 실루엣 또는 단면을 보여줄 수 있지만 내부 두께와 깊이를 삭제하지 않는다. 길이 방향 단면 연결 모델을 첫 실험 후보로 삼는다. 복잡한 비대칭이나 접힘 표현이 필요하면 다른 모델을 검토한다.

## 제안: 상태 전이

소재 확인 → 작업 위치 선택 → 타격 → 국소 형태 갱신 → 형태 확인 → 반복 → 완료 판정. 재가열·열 상태·도구 교체는 아직 필수 규칙으로 넣지 않는다. 필요성이 확인되면 별도 결정으로 추가한다.

## 제안: 평가

목표 대비 형태 오차와 국소 두께 편차를 후보로 둔다. 한 개의 겉보기 실루엣만 맞춰도 숨은 두께 오류를 놓치지 않아야 한다. 평가 차이를 화면에서 설명할 수 있어야 한다. 표면 완성도와 재료 손실까지 평가할지는 미정이다. 완제품 종합 평가는 하지 않는다.

## 제안: 검증

- 타격이 없는 영역은 정한 영향 범위 밖에서 임의로 변형되지 않는다.
- 두께·깊이가 다른 형상을 내부적으로 구분한다.
- 저장·복구 뒤 형상이 동일하게 유지된다.
- 같은 초기 상태와 입력은 재현 가능한 결과를 낸다.
- 형태 오차가 줄었을 때 피드백이 이를 설명한다.
- 회전·카메라 표시를 바꿔도 원본 형태가 손실되지 않는다.

## 미정

타격·회전 입력, 체적 보존, 변형 물리, 열·재가열, 도구, 목표 형상, 재료, 오차 계산, 시점, 접근성, 해금 순서와 성능 목표.
