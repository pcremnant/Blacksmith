# 용해 미니게임

## 확정

튜토리얼은 용해부터 시작한다(S03). 작업자는 이 공정의 품질로 평가받고 건별 급여를 받는다. 구체 조작법은 확인된 대화에 없다.

## 제안: 목표와 조작

재료를 다음 작업에 넘길 수 있는 용융 상태로 만든다. 작업 배정을 확인하고 가열 강도를 조절한 뒤 완료 시점을 선택한다. 화면에는 현재 열 상태, 목표 구간, 진행 안내를 표시한다. 임시 시제품에서는 단일 가열 입력과 완료 입력만 사용한다.

## 제안: 내부 상태

입력은 재료 식별자와 작업 조건, 출력은 용해 작업 결과와 다음 공정용 재료 상태다. 진행 중 온도, 목표 구간 체류 시간, 과열 노출을 관리한다. 실제 금속별 온도나 물리식을 확정하지 않는다. 재료별 값은 설정으로 분리한다.

## 제안: 평가와 피드백

목표 구간 유지와 완료 시점 적합성을 평가 후보로 둔다. 과열을 별도 감점할지는 미정이다. 피드백 예시는 ‘목표 구간에서 조금 더 유지해 보세요’다. 다음 공정의 실패로 용해 점수를 다시 깎지 않는다.

## 제안: 교육·예외·검증

첫 연습은 가열 입력과 목표 구간 도달만 설명하고, 다음 연습에서 유지·완료 판단을 추가한다. 정지 중에는 상태가 진행되지 않게 한다. 완료 입력은 한 번만 처리하며 결과를 다시 열어도 중복 정산되지 않아야 한다. 과열·조기 완료·중단 상태를 구분한다.

## 미정

연료, 투입량, 합금, 불순물, 가열 물리, 조작 장치, 제한 시간, 실패 기준, 평가 가중치, 목표 온도와 교육 작업 수.
