# 연마 미니게임

## 확정

단조보다 비중이 낮고 주조처럼 단순화한다(S02). 해당 공정의 품질만 평가하고 건별 급여를 지급한다(S03).

## 제안: 목표와 조작

작업물의 지정 표면을 정돈한다. 간단한 한 방향 입력 또는 진행량을 채우고 멈추는 입력을 후보로 둔다. 자유 표면 도색이나 복잡한 타이밍 연속 입력은 첫 시제품 범위에 넣지 않는 것을 제안한다.

## 제안: 상태·평가

입력은 작업물과 목표 표면 상태, 출력은 연마 결과다. 연마 진행량과 구역별 완료 상태를 관리한다. 적정 작업량과 균일성을 평가 후보로 둔다. 과연마를 구현할지는 미정이다. 앞선 공정의 형태 오차를 연마 책임으로 평가하지 않는다.

## 제안: 피드백·검증

정돈할 구역과 완료 상태를 색상 외 표시로 구분한다. 완료 전후 차이가 눈에 보여야 한다. 완료 입력 중복 처리와 진행량 범위 이탈을 막는다. 단조보다 배우기 쉽고 반복 부담이 낮은지 확인한다.

## 미정

날 세우기와 표면 마감의 구분, 도구, 구역 수, 입력 방식, 과연마, 형상 변경 여부, 점수 공식, 작업 시간, 해금 순서.
