# 미정 질문과 결정 시점

모든 항목은 미정이다. 답변을 받기 전 임시 구현은 교체 가능한 제안으로 유지한다.

| 우선순위 | 질문 | 필요한 시점 |
|---|---|---|
| 1 | PC·모바일 등 어느 플랫폼인가? 입력은 무엇인가? | 실행 프로젝트 생성 전 |
| 1 | 엔진 또는 기존 개발 코드가 있는가? | 실행 프로젝트 생성 전 |
| 1 | 단조의 작업 대상은 어떤 장비·형상인가? | 형태 모델 실험 전 |
| 1 | 3D 데이터를 어떤 시점·단면·실루엣으로 보여줄 것인가? | 단조 조작 설계 전 |
| 2 | 용해 다음 공정의 해금 순서는 무엇인가? | 전체 튜토리얼 연결 전 |
| 2 | 공정별 평가 지표와 실수 기준은 무엇인가? | 평가 확정 전 |
| 2 | 기본급·품질 차등 폭·화폐 단위는 무엇인가? | 경제 조정 전 |
| 2 | 누적 평가를 어떻게 집계하고 입단 문턱은 무엇으로 정하는가? | 입단 구현 전 |
| 2 | 입단 기준 미달이면 어떤 기회를 주는가? | 입단 구현 전 |
| 2 | 중단·실패·연습·재작업에도 급여를 주는가? | 정산 규칙 확정 전 |
| 2 | 왕국 의뢰의 수량·기한·완료 조건은 무엇인가? | 서사 진행 구현 전 |
| 3 | 아트·음향·접근성·저장 방식은 무엇인가? | 표현과 설정 제작 전 |
| 3 | 정식 길드원 이후의 핵심 플레이는 무엇인가? | 튜토리얼 이후 확장 전 |

## 문서 보완에 필요한 자료

조회되지 않은 초기 기획 대화나 기존 Markdown이 있으면 공정 조작·목표·형태 데이터 논의를 우선 대조한다. 새 자료를 받았다는 이유만으로 모든 제안을 확정으로 바꾸지 않고 사용자 결정이 확인되는 부분만 승격한다.
