# 수습에서 정식 길드원까지

## 확정된 서사

길드는 왕국의 대규모 의뢰를 수행하기 위해 수습을 모집한다. 플레이어는 인턴으로 지원하고, 용해부터 공정을 차례로 배운다. 참여 공정의 품질 평가와 건별 급여가 쌓인다. 왕국 의뢰가 완료될 무렵 누적 평가에 따라 정식 입단하며 튜토리얼이 끝난다. 근거: S03.

## 제안: 상태 흐름

`모집 안내 → 용해 교육 → 용해 작업·정산 → 추가 공정 교육·작업 → 의뢰 마무리 → 누적 평가 확인 → 정식 입단 → 튜토리얼 완료`

용해 이후 추가 공정의 순서는 미정이다. 구현은 순서를 데이터로 바꿀 수 있도록 한다. 단순화된 공정도 교육 없이 갑자기 배정하지 않는 것을 제안한다.

## 제안: 각 교육의 구성

1. 목표와 지금 평가하는 공정만 설명한다.
2. 교관의 짧은 시범 또는 정지 안내를 제공한다.
3. 안내 연습에서 조작과 결과의 관계를 확인한다.
4. 독립 작업 결과에 공정 점수와 급여를 보여준다.
5. 기록부에서 이전 결과와 비교한다.

평가받는 첫 작업부터 유급인지, 시범·연습에도 급여를 주는지는 미정이다.

## 제안: 회복과 저장

설명은 다시 읽을 수 있고 연습은 재시도할 수 있게 한다. 정산 완료 후 저장하며 교육 해금도 함께 보존한다. 작업 중 종료 시 처음부터 다시 시작할지, 중간 복구할지는 미정이다. 저평가 시 추가 교육을 제공하는 방향을 제안하되 입단 자동 통과로 확정하지 않는다.

## 수용 기준 제안

- 새 게임의 첫 교육은 용해다.
- 해금 전 공정은 갑자기 필수 작업으로 배정되지 않는다.
- 배운 공정의 작업 기록과 누적 평가를 확인할 수 있다.
- 왕국 의뢰 마무리와 입단 평가가 연결된다.
- 입단 판정은 저장된 누적 기록을 사용한다.
- 튜토리얼 완료 이후 콘텐츠가 없어도 완료 상태를 명확히 표시한다.

## 미정

서사 분량, NPC와 대사, 의뢰 진행 조건, 필요 작업 건수, 입단 미달 분기, 건너뛰기, 정식 입단 후 시작 위치와 콘텐츠.
